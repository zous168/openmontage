# 视频制作中的排版

> 资料来源：School of Motion 排版指南、legibility.info 视频文字规则、Wave.video 字体
> 搭配研究、EBU/SMPTE 广播标准、Netflix 字幕规范、BBC 字幕指南、
> WCAG 2.1 对比度要求、Easings.net、postplanify.com 安全区数据（2026）

## 速查卡

```
标题字号：       1080p 下 60-90px  |  4K 下 120-180px
正文字号：       1080p 下 40-60px  |  4K 下 80-120px
字幕字号：       1080p 下 42px 以上 |  视频高度的 3-5%
每行最多字符：   32-42（字幕） |  30（叠加层）
最多行数：       2（字幕）     |  3（叠加层）
阅读速度：       每秒 21 字符   |  每分钟 160-200 词
标题安全区：     画面的 80%（1080p 下边距 192px）
动作安全区：     画面的 90%（1080p 下边距 96px）
字体族：         每支视频最多 1-2 种
对比度：         至少 4.5:1，最佳 7:1
淡入时长：       不透明度 0.3 秒  |  滑动/缩放 0.5-1.0 秒
```

## 字体选择

### 推荐的视频字体

| 类别 | 字体 | 用于 |
|----------|-------|---------|
| **正文 / 字幕** | Inter、Open Sans、Roboto、Source Sans Pro、Lato、DM Sans | 所有正文、字幕 |
| **大标题** | Montserrat Bold、Bebas Neue、Oswald Bold、Poppins Bold | 标题、章节头、关键数据 |
| **编辑风** | Playfair Display、Roboto Slab | 奢华、电影感、纪录片 |
| **系统安全字体** | Helvetica Neue、Arial、Avenir Next | 无法使用自定义字体时 |

### 字体搭配规则

- 每支视频限制在 **1-2 种字体族** —— 再多就是视觉噪声
- 用一款**展示型/粗体标题**字体搭配一款**中性正文**字体
- 标题与正文的字号差：至少**大 50%**
- 动态图形和字幕用**无衬线**（在运动中依然立得住）
- **衬线体**只用于电影感标题卡和编辑类内容
- **手写体/装饰体**：只用于主标题，绝不用于正文，绝不用于运动中

### 成熟搭配

| 标题 | 正文 | 风格 |
|---------|------|-------|
| Bebas Neue | Open Sans | 强冲击，社交广告 |
| Montserrat Bold | Lato | 干净现代 |
| Oswald Bold | Raleway | 强对比 |
| Playfair Display | Inter | 编辑风 |
| Poppins Bold | Poppins Light | 单一字体族的层级 |

## 文字尺寸

### 可读的最小字号

| 元素 | 1080p（px） | 4K（px） | 备注 |
|---------|-----------|---------|-------|
| 标题 / 主视觉文字 | 60-90 | 120-180 | 必须在封面图尺寸下也可读 |
| 正文 | 40-60 | 80-120 | 可读性的绝对下限 |
| 字幕 | 42+ | 84+ | 无障碍要求 |

## 安全区

### 广播标准

| 区域 | 覆盖 | 1080p 下边距 | 用途 |
|------|----------|----------------|---------|
| **标题安全区** | 画面的 80% | 水平 192px，垂直 108px | 所有文字必须在其内 |
| **动作安全区** | 画面的 90% | 水平 96px，垂直 54px | 所有重要内容 |

在 1920x1080 下：标题安全区 = 内部 **1536x864px**
在 3840x2160 下：标题安全区 = 内部 **3072x1728px**

|----------|-----------|----------|-------------|------------|
| **TikTok** | 900x1492 | 108px | 320px | 120px |
| **Instagram Reels** | 996x1400 | 210px | 310px | 84px |
| **YouTube Shorts** | 984x1500 | 120px | 300px | 96px |

## 文字动画时序

### 屏幕停留时长

- 阅读速度：最短停留时间按**每秒 13 个字符**计
- 30 个字符的一行：至少 **2.3 秒**
- 通用规则：**每 63 个字符 3 秒**
- 标题卡：**3-6 秒**
- 动画结束之后，静止保持**每 13 个字符 1 秒**

### 动画时长

| 动画类型 | 时长 | 使用场景 |
|---------------|----------|----------|
| 淡入/淡出 | 0.3-0.5 秒 | 克制、通用 |
| 滑动 / 缩放入场 | 0.5-1.0 秒 | 标准动态图形 |
| 动态排版入场 | 1.0-2.0 秒 | 醒目、有活力 |
| 下三分之一入场 | 1.0-2.0 秒 | 讲述者身份标识 |
| 下三分之一退场 | 0.5-1.0 秒 | 快速离场 |

### 缓动曲线

| 缓动 | 三次贝塞尔 | 用于 |
|--------|-------------|---------|
| **easeOutCubic** | `(0.33, 1, 0.68, 1)` | 文字入场（减速到位）—— **默认选择** |
| **easeOutQuart** | `(0.25, 1, 0.5, 1)` | 更利落的入场，动态排版 |
| **easeInOutQuad** | `(0.45, 0, 0.55, 1)` | 平滑的位置过渡 |
| **easeInOutCubic** | `(0.65, 0, 0.35, 1)` | 缩放和不透明度变化 |
| **easeInCubic** | `(0.32, 0, 0.67, 0)` | 退场（加速离开） |

文字动画**绝不使用 linear 缓动** —— 那会显得机械。

### 揭示手法

| 手法 | 观感 | 适用于 |
|-----------|------|----------|
| 遮罩揭示 | 电影感 | 标题卡、高端内容 |
| 缩放弹出 | 有活力 | 社交媒体、短视频 |
| 逐字符错峰 | 自然流动 | 动态排版 |
| 逐词同步 | 有吸引力 | 口播人像字幕、TikTok |
| 淡入 | 克制 | 专业、企业 |

## 字幕排版

### 规格

| 参数 | 取值 | 来源 |
|-----------|-------|--------|
| 字号 | 1080p 下 42px 以上 | 无障碍标准 |
| 每行最多字符 | 32-42 | 取决于平台（见下） |
| 最多行数 | 每块 2 行 | 通用标准 |
| 行距 | 1.3 倍 | 可读性标准 |
| 背景 | 半透明黑，70-80% 不透明度 | 对比度要求 |
| 备选样式 | 白字 + 2-4px 深色描边 | 无底框样式 |
| 最低对比度 | 4.5:1（黑底白字 = 21:1） | WCAG AA |
| 底部边距 | 距边缘至少 60px | 避开移动端手势区 |
| 画面宽度占比 | 最多 90% | 符合标题安全区 |

## 下三分之一

### 标准规格（1080p）

- 叠加区域：**1920x360px**（底部三分之一）
- 无衬线字体（Helvetica、Open Sans、Roboto）
- 白字加投影，或半透明背景条
- 姓名：粗体，字重更大
- 头衔/副标题：字重更轻，字号更小

### 时序

| 阶段 | 时长 |
|-------|----------|
| 入场动画 | 1-2 秒 |
| 展示 | 3-6 秒 |
| 退场动画 | 0.5-1 秒 |

## 对比度与可读性

### WCAG 要求

| 元素 | 最低对比度 | 标准 |
|---------|----------|----------|
| 正文 | 4.5:1 | WCAG AA |
| 大号文字（>18pt） | 3:1 | WCAG AA |
| 增强级正文 | 7:1 | WCAG AAA |
| UI 组件 | 3:1 | WCAG 2.1 |

### 视频上叠文字的手法

1. **半透明底框** —— 文字后面 70-80% 不透明度的黑（最可靠）
2. **文字描边** —— 亮色文字外围 2-4px 深色描边
3. **投影** —— 细微阴影制造纵深（在杂乱背景上不太可靠）
4. **局部压暗** —— 文字区域后面加渐变叠加
5. **全屏叠加** —— 文字密集的画面用 30-50% 的深色叠加

## 应用到 OpenMontage

在 compose/assets 阶段生成视频文字时：

1. **字体选择** —— 使用上面推荐的视频字体；正文优先 Inter 或 Open Sans，标题用 Montserrat Bold
2. **字号核对** —— 1080p 下任何文字元素都不得低于 40px
3. **安全区** —— 所有文字都在 80% 标题安全区内；竖屏/短视频用 900x1400px 通用安全区
4. **字幕样式** —— 42px 以上，最多 2 行，每行最多 42 字符，半透明背景 75% 不透明度
5. **动画** —— 入场用 easeOutCubic，动画结束后按每 13 个字符至少停留 1 秒
6. **对比度** —— 在一帧有代表性的调色后画面上验证至少 4.5:1；优先深底白字（21:1）
7. **平台适配** —— 查上面的平台安全区表并相应调整文字位置
8. **Remotion 渲染** —— 所有字体族都必须在组件里通过 `@import` 或 `fontFamily` 加载；测试字体在 Docker/Lambda 环境中能正确渲染
