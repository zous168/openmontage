# 增强策略技能

## 何时使用

当你要决定如何增强口播人像素材时应用本技能：使用哪些
面部/色彩/音频预设、添加什么叠加层，以及如何在
增强的可见度与自然度之间取得平衡。

## 增强工具

| 工具 | 作用 | 推荐预设 |
|------|-------------|-------------------|
| `face_enhance` | 皮肤柔化、锐化、肤色校正 | `talking_head_standard` |
| `color_grade` | 带强度控制的电影感色彩 | `cinematic_warm`，强度 0.85 |
| `audio_enhance` | 响度归一化、降噪、EQ | `clean_speech` |
| `code_snippet` | 把代码渲染成带样式的叠加图 | `monokai` 主题 |
| `diagram_gen` | 生成方框图/流程图作为叠加图 | `dark` 主题 |
| `image_selector` | AI 生成的插画（需要 API key） | — |

## 增强链

按此顺序应用 —— 每一步都是可选的，失败时会被优雅跳过：

```
原始素材
  → 字幕烧录（video_compose）
  → 面部增强（face_enhance）
  → 调色（color_grade）
  → 音频增强（audio_enhance）
  → 最终编码（video_compose）
```

### 面部增强预设

| 预设 | 何时使用 |
|--------|-------------|
| `talking_head_standard` | 任何口播人像的默认项 —— 柔化 + 锐化 + 暖调 |
| `soft_skin` | 毛孔明显的摄像头素材 —— 温和柔化 |
| `sharpen` | 画面发虚/模糊的相机 —— 增加边缘清晰度 |
| `brighten` | 昏暗/曝光不足的素材 —— 提亮暗部和中间调 |
| `denoise` | 有噪点的素材（弱光、高 ISO）—— 时域降噪 |

### 调色配置

| 配置 | 观感 | 强度 |
|---------|------|-----------|
| `cinematic_warm` | 暖色高光、暗部提亮、轻微加饱和 | 0.85 |
| `cinematic_cool` | 青色暗部、橙色高光 | 0.7 |
| `bright_clean` | 鲜艳、提亮，YouTube 风 | 0.8 |
| `moody_dark` | 压死的黑、低饱和 —— 戏剧化 | 0.6 |
| `neutral` | 最小校正 —— 仅归一化色阶 | 1.0 |

### 音频增强预设

| 预设 | 何时使用 | 目标 |
|--------|-------------|--------|
| `clean_speech` | 口播人像默认项 —— 完整处理链 | -16 LUFS |
| `voice_clarity` | 说话人声音发闷 —— 提升 3kHz/5kHz 的临场感 | -16 LUFS |
| `podcast` | 访谈/播客 —— 更重的压缩 | -16 LUFS |
| `noise_reduce` | 嘈杂环境 —— 激进的 FFT 降噪 | -16 LUFS |
| `normalize_only` | 干净的源，只需匹配响度 | -16 LUFS |

## 叠加层增强类型

| 类型 | 何时使用 | 工具 | 位置 |
|------|-------------|------|-----------|
| **文字叠加** | 关键术语、统计数字、引语 | video_compose overlay | 上三分之一或下三分之一 |
| **代码片段** | 技术内容、API 示例 | code_snippet → overlay | 画面一侧或全屏 |
| **图表** | 用视觉方式解释概念 | diagram_gen → overlay | 画面一侧或全屏 |
| **下三分之一条** | 讲述者姓名、话题标签 | video_compose overlay | 画面底部 20% |

## 叠加层密度指引

### 短视频（< 60 秒）
- 高密度：每 3-5 秒一个叠加层
- 视觉变化快，文字醒目
- 字幕**必需**（多数观众静音观看）

### 中等长度（1-10 分钟）
- 中等密度：每 10-20 秒一个叠加层
- 让讲述者在某些段落独自承载，不做视觉争夺

### 长视频（> 10 分钟）
- 低密度：每 30-60 秒一个叠加层
- 只在内容确实受益时才增强（关键论点、复杂话题）

## 摆放规则

1. **绝不遮挡讲述者的脸** —— 眼睛、鼻子、嘴必须保持可见
2. **字幕放在底部 20%** —— 竖屏 margin_v: 50，横屏 40
3. **位置保持一致** —— 一旦把叠加层放在左侧，就一直放左侧
4. **文字叠加在屏幕上停留 2-5 秒** —— 长到能读完，短到不让人觉得卡住

## 决定增强什么

对脚本的每一段自问：

1. 讲述者是否在解释某个视觉性内容？→ 加一张图表（`diagram_gen`）
2. 是否有关键统计数字或引语？→ 加一个文字叠加
3. 是否有代码或技术内容？→ 加一张代码截图（`code_snippet`）
4. 讲述者是否已连续出镜超过 30 秒？→ 考虑 B-roll 或叠加层
5. 这是开场或结尾吗？→ 用醒目的文字叠加呈现核心信息

## 质量检查清单

- [ ] 面部增强看起来自然 —— 没有过度磨皮或发橙
- [ ] 调色可见但克制 —— 肤色健康
- [ ] 音频已归一化到目标 LUFS —— 全片音量一致
- [ ] 字幕在手机上可读，位于面部下方
- [ ] 叠加层带来了价值（而不只是装饰）
- [ ] 增强密度与内容长度和平台相匹配
