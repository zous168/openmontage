# Flow 连线视觉规范

本文件与 `src/edgeStyle.ts` 保持一致；实现逻辑以 `edgeStyle.ts` 为准。

## 线型含义（先看线型，再看颜色）

| 线型 | 含义 |
|------|------|
| **实线** | 已接通：上下游在此边上已有明确状态（完成、进行中、待审批） |
| **虚线** | 未接通：下游尚未轮到，或路径因失败/门控而中断 |

## 颜色与动画

| 外观 | 条件 | 说明 |
|------|------|------|
| 绿色实线 | 上游已完成，且下游也已完成 | 产物已传递 |
| 蓝色实线 + 沿边流动光点 | **连入** `in_progress` 节点；或「已完成 → 待运行下一阶段」 | 工作正在**该节点内**进行 |
| 蓝色实线（无光点） | 连入 `in_progress` 且 `stalled` | 可能卡住 |
| 琥珀色实线 | 连入 `awaiting_human` 节点 | 门控：等人批准 |
| 灰色虚线 | 未接通；**含运行节点 → 后面未开始阶段** | 还没轮到 |
| 红色虚线 | 连入 `failed` 节点 | 失败断点 |

## 顺序边判定（A → B）

1. A 失败 → 灰虚线  
2. B 失败 → 红虚线  
3. A 待审批 → 灰虚线（门控下游）  
4. B `blocked_by_upstream` → 灰虚线  
5. A 进行中 & B 未开始 → **灰虚线**（运行节点后面保持未接通）  
6. B 进行中 → **蓝实线 + 光点**（连入运行节点）  
7. B 待审批 → 琥珀实线  
8. A、B 均已完成 → 绿实线  
9. A 已完成且 B 是「下一阶段 / 待运行」→ **蓝实线 + 光点**  
10. 其他 → 灰虚线  

## 输入 → 首阶段

与「连入首阶段」相同：首阶段 `in_progress` 时为蓝实线 + 光点；首阶段完成后为绿实线；首阶段 `is_next` 且 pending 时为蓝实线 + 光点（预热，表示即将启动）。

## 节点进度文案（与边独立）

| 节点状态 | 主文案 |
|----------|--------|
| pending + is_next | 待运行 |
| in_progress + activity_hint | 具体步骤（如「正在运行 video_analyzer」） |
| in_progress + active_run_id | 运行中 |
| in_progress + stalled | 可能卡住 N 分钟 |
| awaiting_human | 待审批 |
| completed | 已完成 |
| failed | 失败 |

顶部进度条：`已完成数/总阶段 · 当前阶段名 · activity_hint（如有）`。
